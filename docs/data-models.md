## Data Models

### Entity Relationship

```
Tenant (1) ──< (M) User
Tenant (1) ──< (M) Customer
Tenant (1) ──< (M) Product
Tenant (1) ──< (M) Order
Tenant (1) ──< (M) Event
Customer (1) ──< (M) Order
```

### Tenant
Root entity for multi-tenancy. Each Shopify store gets one tenant.

| Field | Type | Description |
|-------|------|-------------|
| id | UUID | Primary key |
| name | String | Store name |
| shopifyShop | String? | Shopify domain (e.g., demo.myshopify.com) |
| apiKey | String | Unique API key for authentication |
| createdAt | DateTime | Creation timestamp |

### User
Dashboard users with email/password authentication.

| Field | Type | Description |
|-------|------|-------------|
| id | UUID | Primary key |
| tenantId | UUID | Foreign key to Tenant |
| email | String | User email (unique per tenant) |
| password | String | bcrypt hashed password |
| name | String? | Display name |
| createdAt | DateTime | Registration timestamp |

### Customer
Shopify customers ingested via webhooks.

| Field | Type | Description |
|-------|------|-------------|
| id | UUID | Primary key |
| tenantId | UUID | Foreign key to Tenant |
| shopifyId | String | Shopify customer ID (unique) |
| email | String? | Customer email |
| firstName | String? | First name |
| lastName | String? | Last name |

### Product
Shopify products.

| Field | Type | Description |
|-------|------|-------------|
| id | UUID | Primary key |
| tenantId | UUID | Foreign key to Tenant |
| shopifyId | String | Shopify product ID |
| title | String | Product name |
| sku | String? | Stock keeping unit |
| price | Float? | Price |

### Order
Shopify orders with revenue data.

| Field | Type | Description |
|-------|------|-------------|
| id | UUID | Primary key |
| tenantId | UUID | Foreign key to Tenant |
| shopifyId | String | Shopify order ID (unique) |
| totalPrice | Float | Order total |
| currency | String | Currency code (USD, EUR, etc.) |
| createdAt | DateTime | Order creation time |
| customerId | UUID? | Foreign key to Customer |

### Event
Generic event store for custom Shopify events (cart abandoned, checkout started, etc.).

| Field | Type | Description |
|-------|------|-------------|
| id | UUID | Primary key |
| tenantId | UUID | Foreign key to Tenant |
| type | String | Event type (e.g., "events/cart_abandoned") |
| payload | JSON | Event data |
| createdAt | DateTime | Event timestamp |

## Multi-Tenancy Strategy

**Row-Level Isolation**: All domain tables include `tenantId` foreign key. Queries automatically filter by tenant using the API key provided in request headers.

**Benefits**:
- Simple schema
- Cost-effective (single database)
- Easy to query across tenants for analytics

**Trade-offs**:
- Requires careful query filtering
- Shared database connection pool
- For enterprise scale, consider schema-per-tenant or database-per-tenant
